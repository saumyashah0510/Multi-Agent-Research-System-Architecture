# Role Workbook: Member 6 - Citation & Bibliography Agent

## 📋 Role Overview & Scope
- **Role:** Citation Formatting & Export Engine Developer.
- **Goal:** Format literature references into standardized citation styles (BibTeX, APA, IEEE, Harvard) and build report export functions (Markdown, PDF, JSON).
- **Owned Files:**
  - `backend/app/agents/citation_agent.py`
  - `backend/app/services/exporter.py`
  - `backend/tests/test_citation_agent.py`

1. Citation formatting engines (APA 7th, IEEE, Harvard, BibTeX).
2. Report exporter service (Markdown generator, PDF exporter, JSON exporter).
3. Unit tests verifying citation formatting and file exports in `backend/tests/test_citation_agent.py`.
