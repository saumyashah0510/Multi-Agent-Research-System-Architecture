# Role Workbook: Member 9 - DevOps, Cloud Infrastructure & CI/CD

## 📋 Role Overview & Scope
- **Role:** DevOps, Cloud Architect & Infrastructure Engineer.
- **Goal:** Containerize microservices with Docker/Docker Compose, write Terraform infrastructure scripts (AWS S3, EC2), and configure GitHub Actions CI/CD workflows.
- **Owned Files:**
  - `Dockerfile`
  - `docker-compose.yml`
  - `terraform/`
  - `.github/workflows/ci.yml`

---

## 🎯 Step-by-Step Task Breakdown
1. Multi-stage Python `Dockerfile` for backend application.
2. `docker-compose.yml` linking FastAPI, PostgreSQL (pgvector), and Redis.
3. Terraform scripts for AWS EC2, S3 bucket (PDF storage), and security groups.
4. Maintenance & updates for `.github/workflows/ci.yml`.
